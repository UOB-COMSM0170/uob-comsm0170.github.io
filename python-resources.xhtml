Recommended self-study pathway

These official resources provide a suggested progression from running notebooks to preparing data, visualising results, and building machine-learning models.

  1. Welcome to Google Colab — learn how to create and run Python notebooks in the browser without local setup.
  2. The official Python tutorial — revise variables, control flow, functions, data structures, modules, and exceptions.
  3. NumPy: the absolute basics for beginners — learn arrays, shapes, indexing, vectorised operations, and basic numerical work.
  4. pandas getting-started tutorials — practise loading, selecting, cleaning, summarising, combining, and plotting tabular data.
  5. Matplotlib tutorials — learn to create clear plots and customise figures, axes, labels, legends, and layouts.
  6. Getting started with scikit-learn — learn estimators, preprocessing, model fitting, prediction, evaluation, and pipelines.

How to study effectively

  • Type and run examples yourself rather than only reading them.
  • Change values and parameters, predict the result, and then check your prediction.
  • Keep brief notes on errors you encounter and how you fixed them.
  • Use a small public dataset to combine Python, pandas, visualisation, and modelling practice.
